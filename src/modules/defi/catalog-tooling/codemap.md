# DeFi catalog tooling

Offline tooling for versioned source snapshots and the generated production fragment. `catalog-generator.ts` strictly validates source snapshots, canonical ABI identity, source references, scoped unresolved-chain assertions, and exact per-function admissions bound to each full canonical source JSON digest. Unadmitted source-derived functions stay inactive candidates. It preserves frozen baselines and deterministic output; historical v2/v3/v4 assembly remains available. V5 uses a fixed explicit 20-snapshot plan and admissions for 138 exact source functions over the complete v4 baseline, including source-hash/ABI bijections and mandatory Ambient scope/hash. V5 CLI assembly/generation/check/diff uses only fixed repository paths; generated output remains a static type-only import. Source status cannot activate functions, and catalog admission is not financial-argument validation, deployment proof, or automatic API-key grant.
