Optional `data/defi-catalog/updates/current.json` is a raw-byte-pinned offline selector for bare `generate`, `check`, and `diff`; it selects the current two-method dForce iUSDC mint/redeem update. Malformed pointers fail closed, and runtime never reads it. Preview and diff are read-only; explicit update builds can write only the selected update folder's catalog.
