# DeFi catalog tooling

Offline tooling for versioned source snapshots and the generated production fragment. `catalog-generator.ts` strictly validates source snapshots, canonical ABI identity, source references, scoped unresolved-chain assertions, and exact per-function admissions bound to each full canonical source JSON digest. Unadmitted source-derived functions stay inactive candidates. It preserves frozen baselines and deterministic output; historical v2/v3/v4/v5/v6 assembly remains reproducible. V6 uses a fixed 27-path plan and `v6-identities.ts`; v7 uses an explicit five-path plan, `v7-identities.ts`, exact 28-binding admissions, and the complete 640-definition/15-scope v6 baseline to assemble 668 definitions. The 28 v7 rows are ordinary, scope-free reviewed bindings; legacy nullable-scope/hash protections and scope grammar remain unchanged. `prepare-v7` remains read-only and produces inactive candidates without applying admissions. Runtime imports only the generated production TypeScript module, never fixtures or source discovery. Current production catalog commands target v7; explicit v6/v5 commands remain available. Admission does not validate financial arguments, deployment identity, execution funding, or assign customer grants.
