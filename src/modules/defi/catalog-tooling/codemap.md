# DeFi catalog tooling

Offline tooling for versioned source snapshots and the generated production fragment. `catalog-generator.ts` strictly validates source snapshots, canonical ABI identity, source references, scoped unresolved-chain assertions, and exact per-function admissions bound to each full canonical source JSON digest. Unadmitted source-derived functions stay inactive candidates. It preserves all 202 definitions in the pinned baseline, adds the reviewed 59 DEX and 54 lending/yield definitions under explicit family-version IDs, and renders a deterministic static catalog; `scripts/defi-catalog/cli.ts assemble` writes only the fixed v2 catalog and `generate/check/diff` operate on the selected version. The generated output is a static type-only import; no runtime authorization logic or existing grant is rewritten. Catalog admission is not financial-argument validation, deployment proof, or automatic user/API-key grant assignment.
