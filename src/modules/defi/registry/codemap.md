# DeFi registry

Shared immutable reviewed-manifest types, deterministic manifest assembly, and source-reviewed proxy patterns. Family builders contribute fragments; active capabilities require execution-proof and source-identity evidence. ZeppelinOS uses only the fixed `REVIEWED_ZEPPELINOS_IMPLEMENTATION_SLOT`. Production assembly includes only the narrowly selected Ethereum USDC/WETH fee-500 swap and its two explicit approval definitions as active; Oracle Gate 1 attempt 3 passed 3/3 for this exact scope, and 67 other definitions remain inactive. This is not a release/deployment claim, broad protocol rollout, or proof of live production UserOperation success. Reviewed ABI identity is Keccak-256 of JSON.stringify over recursively key-sorted ABI JSON (array order retained), and checked getter records may include typed arguments only for `getPool(address,address,uint24)`.
