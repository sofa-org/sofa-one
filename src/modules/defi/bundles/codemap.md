# DeFi capability bundles

Static, versioned profile metadata for exact reviewed capability IDs. `production-bundles.ts` contains literal current profile memberships and literal expected fingerprints; `DefiBundleService` verifies every member, chain inventory, immutable version, and executable identity against the live reviewed manifest before serving metadata. Pause overlays only affect current availability and never mutate membership or fingerprints. Bundles are informational groupings, not grants: the dashboard performs the existing explicit full replacement, and every capability—including a multicall wrapper and each child—still requires its own grant.

The 62 literal 1.0.0 profiles preserve the original 33 objects byte-for-byte and append 29 explicit phase2 selections for 134 unique candidate identities. Exactly is split into two named Optimism market profiles and a separate Auditor enter/exit profile; the other 26 families each have one bounded selection. Across all profiles the 366 selected IDs are disjoint; the largest profile remains 17 members (phase2 maximum 10). The existing 100-grant API-key limit and ten aggregate decoded execution-node limit are unchanged. Membership is a reviewed literal selection, never runtime family discovery, future-source scanning, or an automatic grant. Fingerprints bind exact manifest executable identity and scope. Approval authority remains independent and is neither included nor automatically paired. These profiles describe selected calls, not complete workflows, deployment inventory, funding, liveness, safety, eligibility, liquidity, or financial-argument guarantees. Gate 2 attempt 2 and final independent validation passed for the bounded 27-family addition; this is not 28/55 completion or 90% market coverage.
