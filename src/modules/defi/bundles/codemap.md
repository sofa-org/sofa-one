# DeFi capability bundles

Static, versioned profile metadata for exact reviewed capability IDs. `production-bundles.ts` contains literal current profile memberships and literal expected fingerprints; `DefiBundleService` verifies every member, chain inventory, immutable version, and executable identity against the live reviewed manifest before serving metadata. Pause overlays only affect current availability and never mutate membership or fingerprints. Bundles are informational groupings, not grants: the dashboard performs the existing explicit full replacement, and every capability—including a multicall wrapper and each child—still requires its own grant.

The 33 literal 1.0.0 profiles preserve the original 12 objects and append 21 one-chain FIRST20 selections (20 protocol brands; Maverick has separate Arbitrum and Base profiles) containing 138 unique new IDs. Across all profiles the 232 selected IDs are disjoint; the largest profile has 17 members. The existing 100-grant API-key limit and ten aggregate decoded execution-node limit are unchanged. Membership is a reviewed literal selection, never runtime family discovery, future-source scanning, or an automatic grant. Fingerprints bind exact manifest executable identity and scope. Approval authority remains independent and is neither included nor automatically paired. These profiles describe functions, not complete workflows, deployment inventory, funding, liveness, safety, eligibility, liquidity, or financial-argument guarantees. The phase-one workflow report documents protocol-specific limits; parent full validation and the mandatory FIRST20 Oracle Gate remain pending.
