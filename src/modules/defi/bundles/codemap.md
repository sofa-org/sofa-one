# DeFi capability bundles

Static, versioned profile metadata for exact reviewed capability IDs. `production-bundles.ts` contains literal current profile memberships and literal expected fingerprints; `DefiBundleService` verifies every member, chain inventory, immutable version, and executable identity against the live reviewed manifest before serving metadata. Pause overlays only affect current availability and never mutate membership or fingerprints. Bundles are informational groupings, not grants: the dashboard performs the existing explicit full replacement, and every capability—including a multicall wrapper and each child—still requires its own grant.

The v6 baseline comprises 62 literal 1.0.0 profiles, preserving the original 33 objects byte-for-byte and appending 29 explicit phase2 selections for 134 unique candidate identities. Five phase3 profiles stage 28 exact aggregator identities after an immutable fixture of all 62 baseline objects. Accepted Enso v8 adds one literal root-only profile after an independent 67-profile/394-ID fixture from accepted v7 commit `445d448cca6fb4e8b2c2cf9d649c2a68f4122242`; it adds exactly the Enso `routeSingle` root ID, not its three child IDs. A separate sDAI v9 profile lane now appends one version-1.0.0 selection for exactly the four no-referral SavingsDai operations (deposit, mint, withdraw, redeem) to the independent 68-profile/395-ID fixture from accepted v8 commit `1f27794f65ecaef030d74a15bdd363eeb36c6ec9`. Its four members exclude DAI approval; each operation requires its own grant and DAI approval is independent, never paired or automatic. The candidate profile fingerprint binds the four exact source-qualified declared ABIs. The profile/source candidate is locally staged while the disjoint v9 admissions/catalog writer is active; do not describe v9 as the current accepted catalog or release totals until parent integration, final validation, and mandatory Gate 5 pass. Exactly is split into two named Optimism market profiles and a separate Auditor enter/exit profile; the other 26 phase2 families each have one bounded selection. The 1inch profile contains 12 selected IDs, without a per-key grant-count limit; any request must still respect the existing ten aggregate decoded execution-node limit. Membership is a reviewed literal selection, never runtime family discovery, future-source scanning, or an automatic grant. Fingerprints bind exact manifest executable identity and scope. These profiles describe selected calls, not complete workflows, deployment inventory, funding, liveness, safety, eligibility, liquidity, or financial-argument guarantees. Gate 2 attempt 2 and final independent validation passed for the bounded 27-family addition; 55-protocol completion and 90% market coverage remain unmet.
