# DeFi capability bundles

Static, versioned profile metadata for exact reviewed capability IDs. `production-bundles.ts` contains literal current profile memberships and literal expected fingerprints; `DefiBundleService` verifies every member, chain inventory, immutable version, and executable identity against the live reviewed manifest before serving metadata. Pause overlays only affect current availability and never mutate membership or fingerprints. Bundles are informational groupings, not grants: the dashboard performs the existing explicit full replacement, and every capability—including a multicall wrapper and each child—still requires its own grant.

The nine initial 1.0.0 profiles are seven one-chain Uniswap V3 Position Manager function sets and Ethereum/Base Morpho Blue function sets. The literal union is 75 unique IDs (largest profile: nine); Ethereum and Base each have 15 IDs across their two chain-specific profiles. Existing API-key limit 100 is unchanged. NPM multicall admits one root plus up to eight fixed children (within the existing 10-node bound): child value is inherited from one outer native-value submission, and configured spend limits still apply to that outer request. The three Morpho supply/supplyCollateral/repay calls per chain require empty callback data only and retain ordinary nonpayable value checks. Oracle Gate 3 passed on attempt 2/3 after R1 resolution, with no new material finding; the parent owns the authorized local commit. These profiles are not complete workflow, deployment, funding, risk, or financial-argument guarantees. Do not use family discovery, dynamic membership expansion, or runtime-derived fingerprints to republish profiles.
