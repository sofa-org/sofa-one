# DeFi capability profiles

Profiles are literal reviewed metadata groupings over exact catalog capability IDs. They are returned by the dashboard's IAM/frontend-only read endpoint; they do not grant capabilities or automatically update saved API-key configuration. Grant changes continue through the existing explicit, step-up-protected flow.

Membership is not proof of complete workflows, deployment inventory, runtime identity, funding, liquidity, or financial safety. Pause state and other runtime authorization controls remain independent of profile membership. See [`README.md`](README.md) and the [DeFi catalog workflow](../../../../scripts/defi-catalog/README.md).
