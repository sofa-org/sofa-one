# DeFi capability bundles

Static, versioned profile metadata for exact reviewed capability IDs. `production-bundles.ts` contains literal current profile memberships and literal expected fingerprints; `DefiBundleService` verifies every member, chain inventory, immutable version, and executable identity against the live reviewed manifest before serving metadata. Pause overlays only affect current availability and never mutate membership or fingerprints. Bundles are informational groupings, not grants: the dashboard performs the existing explicit full replacement, and every capability—including a multicall wrapper and each child—still requires its own grant.

The 12 literal 1.0.0 profiles comprise seven one-chain Uniswap V3 Position Manager sets, Ethereum/Base Morpho Blue sets, and three v4 source-qualified selections: Curve 3pool (four functions), PancakeSwap V3 Position Manager on BNB (nine), and one Yearn TokenizedStrategy instance (six). Their union is 94 unique IDs (largest profile: nine); the existing API-key limit 100 is unchanged. Wrapper and child grants are independent; PancakeSwap's one-level wrapper admits up to eight exact children within the existing ten-node bound. Native value is inherited from one outer request and existing spend limits remain. These are function selections, not complete workflow/product, deployment, funding, risk, or financial-argument guarantees. M4 remains locally uncommitted; do not use family discovery, dynamic membership expansion, or runtime-derived fingerprints to republish profiles.
