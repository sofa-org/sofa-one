# Static DeFi capability profiles

`production-bundles.ts` contains nine literal, immutable version `1.0.0` profiles: seven Uniswap V3 Position Manager profiles, one per exact chain deployment, and Morpho Blue profiles for Ethereum and Base. Their 75 unique capability IDs are concrete reviewed catalog identities; startup recomputes each expected fingerprint against type, chain, normalized contract, signature, fixed ABI hash, and optional execution-scope hash. Copy and live availability are excluded, so warning/label changes and pause overlays do not mutate membership identity. A mismatch, unknown member, invalid chain inventory, or duplicate version fails closed. Paused members remain in the returned exact ID list and make the profile unavailable.

These are available-function sets, not complete product workflows or automatic grants. There are 63 NPM IDs and 12 Morpho IDs; the maximum profile size is nine (Ethereum and Base each have 15 IDs across their two profiles). API-key grant limit remains 100. NPM profile members are one `multicall(bytes[])` wrapper plus eight exact child functions. The wrapper permits one-level expansion only: one root and at most eight children fit within the current ten-node bound, recursive calls are denied, and every selected child needs its own exact grant and live unpaused status. Native value is supplied once to the outer transaction and inherited by every selected child; existing key spending limits still apply to that outer request. Whole-contract/residual NPM balance risks remain. There are no NFT permits, NFT transfers, operator approvals, or automatic token funding approvals; any funding approval is independently selected.

Each Morpho profile contains the existing `borrow`, `withdraw`, `withdrawCollateral` and the versioned v3 `supply`, `supplyCollateral`, `repay` calls. Only empty callback data is admitted for the latter three; this does not add wallet callback handlers. Financial arguments remain caller-controlled and approvals are independent. These profiles are not deployment, funding, session-readiness, risk, market-coverage, or complete-workflow assurances.

The IAM + `FrontendOnlyGuard` route `GET /v1/defi-capability-bundles` is a read-only metadata endpoint, omitted from public OpenAPI and unavailable to API-key auth. Previewing additions unions them with the existing selection; replacement/removal requires explicit confirmation through the existing full-set, step-up-protected grant update. Unknown and paused selections remain visible unless explicitly removed. Nothing in the bundle read automatically saves or grants capabilities.

The terminal full suite reported 2,359 passing tests and one opt-in PostgreSQL test skipped; build passed. The parent owns the authorized local commit. This is not a deployment, funded-execution, or 90% coverage claim.
