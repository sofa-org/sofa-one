# DeFi capability profiles

Production profiles are literal, reviewed metadata selections over catalog capability IDs. They support dashboard display and selection only; reading or previewing a profile does not persist grants. Every selected capability remains subject to the existing API-key grant flow and independent authorization, pause, and execution controls.

Profile membership is not a grant, complete workflow, deployment inventory, funding or liquidity claim, runtime identity check, or financial-safety guarantee. See the [DeFi catalog workflow](../../../../scripts/defi-catalog/README.md) and [module code map](../codemap.md).
