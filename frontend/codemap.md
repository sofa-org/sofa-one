# Frontend Root (`frontend/`)

## Responsibility
Owns the SOFA ONE SPA as a standalone package: the Vite + React 19 build/dev toolchain, dependency graph, path aliasing, dev-server proxy, and runtime environment wiring. This directory is the **parent container** for the application source (`src/`) and holds all root-level configuration (`package.json`, `vite.config.ts`, `tsconfig.json`, `.eslintrc.cjs`, `.env*`, `index.html`). It contains no application logic itself — that lives under `src/` (see the child maps). The SPA is a browser client for the NestJS backend; it never stores, logs, or derives private keys (those stay in the Openfort TEE).

Root-level files:
- `package.json` — package metadata, scripts, dependency graph.
- `vite.config.ts` — Vite build/dev config, React + Tailwind plugins, `@/` alias, `/api` proxy, manual chunking.
- `tsconfig.json` — strict TypeScript build config (no emit; Vite emits bundles).
- `tsconfig.tsbuildinfo` — incremental build cache artifact (generated).
- `.eslintrc.cjs` — ESLint config (TypeScript + Prettier).
- `index.html` — HTML entry shell; loads `/src/main.tsx`, Google Fonts (Inter/Newsreader/Source Code Pro).
- `vite-env.d.ts` — Vite client types + `ImportMetaEnv` typing for `VITE_*` vars.
- `.env.example` / `.env` — environment templates / local values (see Configuration).
- `.gitignore` — ignores `node_modules/`, `.next/`, `.env*` (except example), `out/`.
- `dist/` — production build output (generated by `vite build`).
- `.next/` — stale Next.js build artifact (not used; this is Vite, not Next.js).

## Build/Runtime Design
- **Stack**: Vite 6 + React 19 + React Router 7 + Tailwind CSS 4 + TypeScript 5. This is **not** Next.js (the `.next/` dir is a leftover artifact).
- **Scripts** (`package.json`):
  - `dev` → `vite` (dev server, port 3000).
  - `build` → `tsc -b && vite build` (type-check then bundle).
  - `preview` → `vite preview` (serve the production build locally).
  - `lint` → `eslint .` (run separately; root repo lint skips `frontend/`).
- **TypeScript** (`tsconfig.json`): `strict: true`, `noUnusedLocals`/`noUnusedParameters`, `noEmit` (Vite emits), `moduleResolution: "bundler"`, `jsx: "react-jsx"`, `paths: { "@/*": ["./src/*"] }`. `include: ["src", "vite-env.d.ts"]`.
- **Vite** (`vite.config.ts`):
  - Plugins: `@vitejs/plugin-react` + `@tailwindcss/vite` (Tailwind v4 CSS-first, no `tailwind.config.js`).
  - `resolve.alias`: `@` → `./src`.
  - `build.modulePreload: false`; `chunkSizeWarningLimit: 1300`; suppresses third-party `/*#__PURE__*/` annotation warnings.
  - `manualChunks`: `vendor` (react, react-dom, react-router-dom) and `wallet` (@openfort/react, wagmi, viem) for cache-friendly splitting.
- **Styling**: Tailwind v4 via `@import "tailwindcss"` in `src/index.css`, with a `@theme` block defining brand tokens (`brand-bg`, `brand-accent`, etc.) and font families (Inter/Newsreader/Source Code Pro loaded from Google Fonts in `index.html`).
- **Entry**: `index.html` → `/src/main.tsx` → `createRoot` renders `<StrictMode><ErrorBoundary><BrowserRouter><App/></BrowserRouter></ErrorBoundary></StrictMode>`.

## Flow
- **Dev**: `npm run dev` starts Vite on port 3000. Requests to `/api/*` are proxied to the backend (default `http://localhost:3100`, overridable via `VITE_API_PROXY_TARGET`) with the `/api` prefix stripped.
- **Runtime base URL**: `src/lib/api.ts` resolves `API_BASE` = `VITE_API_URL` or `/api` (the Vite proxy). In production builds it throws at module load if `VITE_API_URL` is unset. `getApiBaseUrlForDisplay()`/`getApiBaseUrlModeLabel()` expose the resolved base for the Docs page.
- **App routing** (`src/App.tsx`): `/` → Landing; `/sign-in/*` → SignIn; `/sign-up/*` → redirect to `/sign-in`; `/dashboard` → `AuthProviders → ProtectedRoute → DashboardStepUpGate → DashboardLayout` with nested children (index=Wallet, api-keys, transactions, notifications, billing, docs); `*` → redirect to `/`. All routes are `lazy()`-loaded under a top-level `<Suspense>`.
- **Auth boundary**: public pages drive the Openfort email-OTP flow; authenticated users are redirected to `/dashboard`; unauthenticated dashboard access redirects to `/sign-in` with `state.from` for post-login return. The dashboard enforces a TOTP MFA step-up gate before mounting.
- **Build**: `npm run build` type-checks then emits the production bundle to `dist/` (served by `vite preview` or any static host).

## Integration
- **Backend**: the SPA talks to the NestJS backend over HTTP. In dev it goes through the Vite `/api` proxy; in production it uses `VITE_API_URL` directly. The access-control split is respected: dashboard routes use Openfort IAM bearer tokens (`authFetch`), while only the three public API-key endpoints (`POST /v1/wallets/sign`, `POST /v1/transactions/send`, `GET /v1/transactions/:id`) use explicit API keys (`apiFetch`).
- **Openfort**: `@openfort/react` provides IAM auth (email OTP), the embedded EOA wallet, Shield recovery, and 7702 authorization; `@openfort/react/wagmi` + `wagmi` + `viem` provide the wallet/chain stack. `AuthProviders.tsx` builds a 13-chain wagmi config with public RPC defaults overridable via `VITE_*_RPC_URL`.
- **Blockchain**: `src/lib/calibur.ts` builds EIP-7702-authorized Calibur smart accounts (EntryPoint v0.8) whose user operations are signed by the owner account and submitted through Openfort (or Pimlico on Monad).
- **Dependencies** (`package.json`):
  - Runtime: `@openfort/react`, `@tanstack/react-query`, `lucide-react`, `qrcode`, `react`, `react-dom`, `react-router-dom`, `viem`, `wagmi`.
  - Dev: `@tailwindcss/vite`, `@types/*`, `@typescript-eslint/*`, `@vitejs/plugin-react`, `eslint`, `eslint-config-prettier`, `tailwindcss`, `typescript`, `vite`.
- **Child maps**: `src/codemap.md` (app core), `src/components/codemap.md`, `src/lib/codemap.md`, `src/pages/codemap.md`, `src/pages/dashboard/codemap.md`.

## Configuration
- **Env vars** (see `.env.example`; `.env` holds local values, gitignored):
  - `VITE_OPENFORT_PUBLISHABLE_KEY` — required; Openfort IAM publishable key (email OTP / sign-in).
  - `VITE_OPENFORT_SHIELD_PUBLISHABLE_KEY` — required for dashboard; Openfort Shield wallet recovery.
  - `VITE_OPENFORT_FEE_SPONSORSHIP_ID` — optional; Openfort sponsorship policy for 7702 UserOperations.
  - `VITE_PIMLICO_API_KEY` — Pimlico RPC/bundler for Monad UserOperations (Openfort RPC does not support Monad); optional `VITE_PIMLICO_RPC_URL_<chainId>` overrides.
  - `VITE_API_URL` — backend base URL; unset → `/api` (Vite proxy). Required in production builds.
  - `VITE_API_PROXY_TARGET` — optional dev-server proxy target (default `http://localhost:3100`).
  - `VITE_*_RPC_URL` — optional browser-safe RPC overrides for wagmi/viem (baseSepolia, base, ethereum, sepolia, polygon, polygonAmoy, monad, monadTestnet, etc.).
- **Typing**: `vite-env.d.ts` declares `ImportMetaEnv` for the `VITE_*` vars consumed in code.
- **Lint**: `.eslintrc.cjs` — `eslint:recommended` + `@typescript-eslint/recommended` + `prettier`, browser/node env, ignores `dist/` and `node_modules/`.
- **Security notes**: private keys never leave Openfort; the SPA only handles the recovery password (browser-local) and signs via the embedded wallet. Raw API keys are shown once with a 2-minute TTL and never persisted. Guarded mutations require a TOTP step-up proof token (session-scoped, cleared on sign-out).
